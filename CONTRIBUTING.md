# Contributing

Use English for source, comments, documentation, issues and pull requests. Keep changes focused and explain the user-visible behavior and validation.

Read docs/ARCHITECTURE.md before changing render ownership or color handling. Run core tests, Android lint and a debug build. Rendering changes also need device instrumentation and visual inspection of exported output. Never describe compile-only checks as device validation.

Preserve upstream attribution and licenses. Do not commit personal sample photographs, downloaded packaging images, generated build files, credentials or signing keys. Synthetic test fixtures and original vector illustrations are preferred.

Use your own Git identity for your contributions. Do not rewrite another author's attribution or add unrelated coauthor trailers. Commit changes to the Android port separately from an upstream submodule update.
